# Validation scope and limitations

The automated fixture is deterministic: two reference records share one COI sequence but disagree at species, one positive read pair matches both, and an unrelated read pair is expected to have no accepted match. The full workflow must assign the positive fragment at genus, keep the negative sample's zero column, and produce a report and manifest. A second test builds a tiny combined BOLD/UNITE database and checks that conflicting taxonomies and source checksums survive. These are software regression checks, not a biological performance estimate.

Before using results for ecological or clinical conclusions, validate against a representative mock community or samples with independent ground truth. Record the database snapshot and its checksum, library preparation, read lengths, sequencing depth, preprocessing parameters, and BarcodeMapper version. Include positive and extraction/library negative controls. Report recall and precision at each taxonomic rank, false positives in negatives, and the fraction of read IDs assigned only to higher ranks or left unclassified. Compare several stringency settings and inspect taxa absent from the reference database. Repeat with multiple samples and assess stability across runs. Publish the expected taxa and count tables alongside the chosen database provenance, subject to provider terms.

BarcodeMapper reports **read IDs with accepted marker alignments**, not organism counts or biomass. Both mates of a pair share an ID and receive one lowest-common-ancestor assignment. The count table propagates each assignment to all named ancestors, so rows are not independent. Identical or similar marker sequences can prevent species resolution; missing or mislabeled reference sequences can cause missed or incorrect assignments. Bowtie2's exhaustive alignment mode can be expensive for repetitive references. fastp filtering and `NM` edit filtering can alter sensitivity by read quality and length. The HTML relative chart is a fraction of the reported assigned/unclassified read IDs, not a compositional abundance estimate for the original sample.
